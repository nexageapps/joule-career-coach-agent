# Changelog

All notable changes to this project are documented in this file.

## [1.0.0] - 2026-11-14

### Added

- Joule Studio solution export for the SuccessFactors Career Coach Agent (`career-story-agent`).
- Read-only MCP tools for career story, strengths, skill gaps, and next steps, using the signed-in employee's own SuccessFactors record.
- DEMOCO mock data for preview. No credentials are stored in this repository.
- 215 tests from the Joule Studio build, with 89.81% coverage.
- Community files: MIT licence, contributing guide, Contributor Covenant code of conduct, security policy, issue and pull request templates, and Dependabot for pip.

### Known issues

- Deployment on SAP Build is blocked by a 5-minute pre-validation timeout. That item is still open.
